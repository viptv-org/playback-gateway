# Archive byte fixtures

These archives contain the decimal byte pattern `0123456789`, not provider media.
`stored.rar` contains the pattern repeated ten times as `clip.mp4`; its RAR4
header and checksums were generated locally and independently accepted by UnRAR.
`compressed.rar` and three `split.part*.rar` files contain the pattern repeated
one thousand times, generated by RAR 7.23 with `-m3 -ep` and `-m0 -v4096b -ep`.
The temporary writer came from the upstream RAR distribution and is not shipped.
Tests verify direct stored ranges, volume-boundary seeking, bounded compressed
extraction, output cleanup and malformed-archive refusal. Real decodable-media
archives and exact commands are in `../rar-media/README.md`.

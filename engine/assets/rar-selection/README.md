# Stored RAR5 selection and encryption fixtures

These files contain original generated byte patterns, with media extensions used
only to exercise selection. They contain no downloaded or provider media.
The temporary writer is [RAR for Linux 7.23](https://www.rarlab.com/download.htm);
its executable is not redistributed. Tests need no installed RAR writer.

Inputs, in archive order:

- `a-small.mp4`: 1,289 bytes, byte `n` equals `n % 131`.
- `b-large.mp4`: 24,007 bytes, byte `n` equals `n % 251`.
- `c-large.mp4`: 24,007 bytes, byte `n` equals `250 - n % 251`.

```sh
rar a -idq -ma5 -m0 -v8192b -ep -ds stored-multi.rar a-small.mp4 b-large.mp4 c-large.mp4
rar t -idq stored-multi.part1.rar
rar a -idq -ma5 -m0 -ep -hpfixture-password encrypted-headers.rar a-small.mp4
rar a -idq -ma5 -m0 -ep -pfixture-password encrypted-member.rar a-small.mp4
```

`fixture-password` is a public fixture value, not an account credential. The
stored archive spans seven volumes. Equal-size members have different content
to prove stable default ties and explicit selection. The two encrypted archives
exercise actual RAR5 header encryption and member encryption refusals.
